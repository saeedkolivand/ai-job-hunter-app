# Privacy: what leaves your device

Last updated: 2026-11-16

Your résumés, generations, applications, and tracked job data live in a local SQLite database on your device (credentials live in the OS keychain); there is **no app-operated backend** collecting them, and no behavioural analytics. **Two things happen automatically, without you asking:** the app checks for updates (GitHub, 10 s after launch then every 4 h, transmitting only your app version and OS/architecture), and sends crash reports to Sentry (error + stack trace, OS, app version, the install type such as snap or Windows installer, the name of the app command that was running, and, for a startup storage failure, which internal store failed and its error code — no paths, no data) when the app breaks — the latter is on by default, asked during setup, switchable off in Settings → Privacy, and redacted of paths, links, hosts, e-mails and credentials before sending. The app's other outbound calls go to services **you** configure or invoke: your AI provider (which receives the résumé and job text you ask it to generate from), job boards you scrape (including the Adzuna, JSearch/RapidAPI, Jooble, Apify and freehire aggregator tiers — freehire being the one that needs no key, tried last), an optional web search you explicitly enable (your provider's own, then a SearXNG-compatible server you set (SearXNG or RustXNG, no key; queries go to that server), then Exa if you add a key; the next runs only when one fails on billing or sign-in), location autocomplete (Photon, with offline fallback), opt-in company-logo enrichment (Clearbit, default **off**), opt-in email-confirmation watching via IMAP (credential user-supplied and OS-keychain-backed; email content never leaves the device), opt-in self-hosted sync between your own devices (default **off**; it sends the same data an app backup holds — applications and their status history, documents, generations, contact profile, job preferences and AI provider routing, never passwords or API keys — only to a sync server **you** configure, with an OS-keychain-backed token), and your optional profile import from GitHub or LinkedIn. Neither the update check nor the crash report ever includes your documents or job data, and the browser extension is excluded entirely from all reporting; see [ADR 0005](knowledge/decision-records/0005-network-egress-privacy-boundary.md).
